# نتيجة التحقق المحلي

تاريخ التحقق: 5 أكتوبر 2026.

- `npm run build`: نجح بناء الإنتاج، بما فيه فحص TypeScript.
- `npm test`: نجحت الاختبارات التسعة للتحقق من البيانات، وتوحيد الهواتف، والموافقة، وكلمات المرور، وفحص المصدر، وحد حجم الطلب، والحفظ الدائم وقيود القاعدة والتعديل والحذف.
- `npm run test:e2e`: نجحت اختبارات المتصفح الثلاثة عبر Edge.
- التقديم والمراجعة والتعديل والحفظ والموافقة الإلزامية ومنع التكرار: اختُبرت فعلياً.
- الدخول الخاطئ والصحيح، جلسة HttpOnly وSameSite، وحظر قراءة وتعديل الطلبات دون دخول: اختُبرت فعلياً.
- البحث بالاسم وبالهاتف بصيغة محلية وأرقام عربية، الفلاتر، الصفحات، التفاصيل، الحالة، الحذف وتسجيل الخروج: اختُبرت فعلياً.
- روابط واتساب: تم التحقق من الرقم الدولي والرسالة في الرابط، دون إرسال رسائل خارجية.
- أحجام 390 و768 و1440 بكسل: لا يوجد تمرير أفقي؛ حُفظت صور الصفحة الرئيسية. اختُبرت الإدارة على الهاتف والكمبيوتر أيضاً.
- كل البيانات التجريبية وحساب الاختبار داخل `.test-data/e2e` المعزولة فقط.

الصور متاحة بعد الاختبارات في `test-results/home-390.png` و`home-768.png` و`home-1440.png` و`admin-mobile.png` و`admin-desktop.png`.

لم يُنشر الموقع على دومين عام. اختُبر مسار قاعدة البيانات على PostgreSQL المدمجة PGlite، ولم يُختبر اتصال PostgreSQL خارجية أو شهادات TLS للاستضافة لعدم توفير إعداداتها. يتطلب الإنتاج تعيين المتغيرات وإنشاء حساب الإدارة وإجراء تحقق بعد النشر كما في README.
